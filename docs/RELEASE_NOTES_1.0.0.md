## Pomo 1.0.0, first release 🍅

A tiny, keyboard-first Pomodoro timer for Windows.

**Highlights**
- Focus / short / long break cycle with configurable durations and long-break interval
- Keyboard-first: every action on a single key, fully keyboard-driven settings
- System tray with live countdown tooltip; global hotkeys (Ctrl+Alt+Space, Ctrl+Alt+P)
- Full-screen mode for a second monitor (F / F11)
- Notifications, soft synthesized chime, volume + mute, auto-start option
- Flat true-black gruvbox theme + light theme; daily stats
- 1.3 MB installer, ~70 MB RAM, ~0% CPU idle

**Install:** download `Pomo_1.0.0_x64-setup.exe` below and run it (per-user install, no admin needed). If SmartScreen warns, choose *More info → Run anyway*.

**Requirements:** Windows 10 / 11, 64-bit.
