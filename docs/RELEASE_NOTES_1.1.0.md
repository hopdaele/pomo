## Pomo 1.1.0: always in view

**New**
- **Mini bar (B):** Pomo shrinks to a slim, always-on-top, CLI-style strip, e.g. `● [██████░░░░] 18:42 focus`. Drag it anywhere, such as just above the taskbar. Double-click, B or Esc expands it again. It's the same window, so it uses no extra memory.
- **Taskbar progress:** Pomo's taskbar button fills as the phase runs and turns yellow when paused.
- **Live tray icon:** the tray icon becomes a draining ring in the phase colour with the minutes left. It is redrawn only when what it shows changes.

**Fixed**
- The taskbar button now always shows the current app icon.

**Performance:** ~74 MB RAM; running in the mini bar ≈0.16% total CPU; running while hidden ≈0.03%.

**Install:** run `Pomo_1.1.0_x64-setup.exe` (per-user, no admin). It updates 1.0.0 in place.
