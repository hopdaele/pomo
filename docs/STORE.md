## Long description

**Focus without the bloat.**

Pomo is a native Windows Pomodoro timer built for people who live on the keyboard. Press Space to start a 25-minute focus session; Pomo handles the breaks, keeps count, and gently chimes when it's time to switch. No account, no subscription, no browser tab to lose.

**Built to disappear**
- 1.3 MB installer, ~70 MB memory, effectively 0% CPU when idle or hidden
- Lives in your system tray with a live countdown tooltip
- Global hotkeys: start/pause and show/hide from any app

**Built for focus**
- Full-screen mode for a second monitor: a huge, calm ring on pure black, with controls that fade away until you need them
- Accurate to the second: survives sleep and never drifts, even when hidden
- Soft synthesized chime, Windows notifications and an optional auto-start of the next phase

**Built for the keyboard**
- Every action has a single key: Space, R, S, 1/2/3, M, P, F
- Settings you can drive entirely with arrow keys
- Shortcut cheat-sheet one keystroke away (?)

**Beautiful by default**
- Flat gruvbox palette on true black (gorgeous on OLED) plus a warm light theme
- Crisp Cascadia Mono typography

**Private by design**
- Zero network access, zero telemetry. Your stats never leave your PC.

**Requirements:** Windows 10 or 11, 64-bit.

## Feature bullets (for comparison tables)
